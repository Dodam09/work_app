# 📌 work_app

**work_app**은 이미지 파일을 업로드하고, 이름을 일괄 변경한 뒤 zip으로 다운로드할 수 있는 웹 앱입니다.

---

## 🚀 주요 기능

- Drag & Drop 또는 파일 선택으로 이미지 업로드
- 이미지명 일괄 변경 (커스텀 접두어 + 번호)
- 변경된 이미지 zip 파일로 다운로드

---

## 🖥️ 데모

👉 [배포된 웹 앱 바로가기](https://work-app-lac.vercel.app/)

---

## 🛠️ 사용 기술

- React
- Next.js
- JSZip
- Emotion CSS

---

## 📦 설치, 실행 및 사용 방법

```bash
# 1) 프로젝트 클론 후 설치
git clone https://github.com/Dodam09/work_app.git
cd work_app
npm install

# 2) 로컬 서버 실행
npm run dev

# 3) 사용 방법
# - 파일을 드래그하거나 업로드 버튼을 클릭해 파일을 선택합니다.
# - 원하는 접두어를 입력 후 일괄변경 버튼을 클릭합니다.
# - 하단에 변경된 이미지가 표시되면 File Download 버튼으로 zip 파일을 받을 수 있습니다.
```
